    Terms and equations

    Refitting a set of terms on one dataset, checking that a term is well formed, and deciding whether two equations state the same law are the three jobs here. The term syntax is described under Equation representation, and what the numbers mean under Score conventions and comparability.

    Name Summary
    kd.evaluate_terms(dataset, terms[, ...]) Evaluate candidate terms against a dataset, fail-loud.
    kd.predict_terms(terms, coefficients[, ...]) Evaluate unsimplified funcall terms, applying saved coefficients once.
    kd.validate_terms(dataset, terms[, ...]) Classify each term as valid / rejected WITHOUT fitting.
    kd.verify_equation(eq, executor[, ...]) Verify an equation on a dataset using its reported coefficients unchanged.
    kd.block_dispersion(dataset, terms[, ...]) Refit the terms on separate grid blocks and measure coefficient spread.
    kd.forward_error(dataset, terms[, ...]) Integrate the equation from the data's first time slice and compare.
    kd.ForwardError(value, reason[, ...]) Outcome of forward_error.
    kd.forward_error_trajectories(trajectories, laws[, ...]) Integrate one law per state along every trajectory and compare.
    kd.TrajectoryForwardError(value, reason[, ...]) Outcome of forward_error_trajectories.
    kd.refit_terms(dataset, terms[, ...]) Prune small terms by their input coefficients, then refit the rest once.
    kd.register_refit_method(name, method) Register a complete measurement method under its declared name.
    kd.refit_methods() Return registered method names, with the built-ins first.
    kd.refit_method(name) Resolve a registered method; unknown names raise ValueError.
    kd.RefitMethod(args, kwargs) A measurement implementation with configuration bound at registration.
    kd.ResolvedFrame(args, kwargs) A fixed target and row/window selection supporting arbitrary subsets.
    kd.FrameFit(coefficients, mse[, ...]) One fixed-support fit, measured on the frame's original target.
    kd.RefitResult(terms, coefficients[, ...]) Outcome of refit_terms.
    kd.RefitFrame(input_identity, lhs_field[, ...]) How one refit measured.
    kd.WeakFormOptions(half_widths, spectrum_tau[, ...]) Window and correction settings of refit_terms(method="weak").
    kd.WeakFormDiagnostics(method_version, spatial_axis[, ...]) What a weak fit integrated and how its solve went.
    kd.ablate_terms(dataset, terms[, ...]) Refit the support, then refit it once without each term.
    kd.AblationResult(baseline, rows[, ...]) Outcome of ablate_terms.
    kd.AblationRow(dropped_term, retained_terms[, ...]) One drop-one refit of ablate_terms.
    kd.score_term_sets(dataset, term_sets[, ...]) Fit several fixed supports in one frame resolved for their union.
    kd.TermSetScores(frame, entries) Outcome of score_term_sets: the shared frame and one entry per set.
    kd.TermSetEntry(terms, fit[, ...]) One term set of score_term_sets: its fit or why it has none.
    kd.refit_constants(dataset, terms[, ...]) Refit the numeric literals inside the terms of a tabular answer.
    kd.ConstantRefit(terms, constants[, ...]) The refit of the numeric literals inside additive-term IRs.
    kd.refine_pinn(dataset, terms[, ...]) Fit a network to a GRID dataset and a law together, coefficients included.
    kd.PinnRefinement(terms, initial_coefficients[, ...]) Outcome of refine_pinn.
    kd.vote_terms(supports, min_count[, ...]) Count each law term once per support and select the frequent ones.
    kd.TermVoteResult(selected, rows[, ...]) Outcome of vote_terms.
    kd.TermVoteRow(law_key, term[, ...]) The count of one law term across the supports.
    kd.law_signature(eq) Build a versioned signature from an equation's active law.
    kd.format_pde(terms, coefficients[, ...]) Build a formatted PDE equation from term strings and coefficients.
    kd.format_record_equation(record) Format the law a sealed run record carries, for display.
    kd.FormattedEquation(latex, unicode[, ...]) Rendered PDE equation plus the underlying SymPy objects.
    kd.to_sympy(code, strict[, ...]) Convert kd IR into a SymPy expression.
    kd.from_sympy(expr) Serialize a supported SymPy expression into kd function-call IR.
    kd.lower_term(text) Return the funcall IR of one term written in product notation.
    kd.jet_polynomial(expression, vocabulary) Return the expansion of expression as monomial -> float coefficient.
    kd.term_monomial_keys(term, fields[, ...]) Return the monomial keys of one term in the names of one input.
    kd.undefined_terms(terms) Return the terms that have no algebraic reading.
    kd.render_lhs_label(lhs_spec) Render an LHS spec to the legacy serialized lhs_label string.
    kd.LhsSpec(field, axis[, ...]) Structured left-hand-side specification for an evolution equation.
    kd.Sketch(pinned, anchored[, ...]) Construct a complete Sketch from typed clauses, or a dataset-bound SketchSpec from shorthand terms and Hole objects.
    kd.SketchSpec(pinned, anchored[, ...]) A shorthand Sketch not yet bound to a dataset; see kd.Sketch.
    kd.Hole(max_terms, min_terms[, ...]) Room for unknown terms in a shorthand Sketch, and the shape they take.
    kd.sketch_from_anchors(dataset, anchors[, ...]) Return a Sketch that requires anchors and admits a bounded rest.
    kd.sketch_from_dict(payload) Strictly decode and revalidate a kd-sketch-v2 payload.
    kd.sketch_to_dict(sketch) Serialize sketch as a JSON-safe kd-sketch-v2 payload.
    kd.save_sketch(sketch, path) Write a Sketch or a SketchSpec to path as JSON.
    kd.load_sketch(source, dataset) Read a Sketch file, from a path or an already decoded mapping.
    kd.EvaluationResult(mse, nmse[, ...]) Result from evaluating an expression or term list.
    kd.TermValidationReport(results, valid[, ...]) Structured result of validate_terms (JSON-dumpable, no fitting).
    kd.TermRejection(term, reason) A single rejected term and the reason it was rejected.
    kd.VerificationReport(signature, form[, ...]) JSON-serializable measurements for one equation on one dataset.
    kd.VerifyPolicy(nmse_max, coeff_atol[, ...]) Thresholds used when reporting and comparing empirical verification.
    kd.SKETCH_EXIT_VERIFY —
    kd.InvalidTermsError(rejected) Raised when one or more terms are rejected and cannot be fitted.
    kd.EvaluationFailedError Raised when the final fit is invalid (solver failure / non-finite MSE).

    evaluate_terms

    Evaluate candidate terms against a dataset, fail-loud.

    Parameters:

    • dataset (PDEDataset) –

      The PDE dataset to evaluate against (never mutated).

    • terms (Sequence[str]) –

      Candidate term strings (canonical funcall IR or product notation). result.terms keeps the caller's spelling and order.

    • skip_invalid (bool, default: False ) –

      When False (default, strict), ANY rejected term raises InvalidTermsError carrying every rejection and nothing is fitted. When True (lenient), rejected terms are dropped with exactly one logger.warning and the survivors are fitted.

    • max_order (int, default: 2 ) –

      Maximum atomic derivative order (-> max_atomic_order).

    • lhs_order (int | None, default: None ) –

      LHS derivative order targeted by the fit (1 -> u_t, 2 -> u_tt; -> DerivativeReqs.lhs_order). Default None DERIVES from dataset.lhs_order (single source of truth).

    • rows (Tensor | None, default: None ) –

      Grid-shaped boolean mask or flat int32/int64 sample indices. Derivatives and term validation run on the complete grid first.

    • fixed (Mapping[str, float] | None, default: None ) –

      Term to coefficient for terms whose coefficient is held, not fitted. Keys are written as terms are (u*u_x and mul(u,u_x) fix one column).

    • sketch (Sketch | SketchSpec | None, default: None ) –

      A kd.Sketch whose pinned terms are the fixed coefficients; its anchored terms and holes do not change the fit.

    validate_terms 

    validate_terms(
    dataset: PDEDataset,
    terms: Sequence[str],
    *,
    max_order: int = 2,
    lhs_order: int | None = None,
) -> TermValidationReport

    Classify each term as valid / rejected WITHOUT fitting.

    Parameters:

    • dataset (PDEDataset) –

      The PDE dataset to evaluate against (never mutated).

    • terms (Sequence[str]) –

      Candidate term strings (canonical funcall IR or product notation); the report names each in the caller's spelling.

    • max_order (int, default: 2 ) –

      Maximum atomic derivative order made resolvable (-> DerivativeReqs.max_atomic_order). Gates terminal tokens such as u_xx; open-form diff*_x calls are not gated.

    • lhs_order (int | None, default: None ) –

      LHS derivative order the tautology guard compares against (1 -> u_t, 2 -> u_tt). Default None DERIVES the order from dataset.lhs_order (the single source of truth).

    Returns:

    • TermValidationReport –

      A TermValidationReport partitioning the terms into valid / rejected, JSON-dumpable via to_dict().

    Raises:

    • ValueError –

      If terms is empty.

    • ValueError –

      Propagated from PlatformBuilder when the resolved LHS field/axis is absent from the dataset, when the resolved lhs_order > max_order (the LHS is read from the same precomputed derivative cache that max_order bounds), or when max_order > 3 (provider cap).

    block_dispersion 

    block_dispersion(
    dataset: PDEDataset,
    terms: Sequence[str],
    *,
    n_blocks: int = 4,
    axis: str | None = None,
    max_order: int = 2,
    lhs_order: int | None = None,
) -> float

    Refit the terms on separate grid blocks and measure coefficient spread.

    Parameters:

    • dataset (PDEDataset) –

      A GRID PDEDataset (never mutated).

    • terms (Sequence[str]) –

      Candidate term strings (canonical funcall IR or product notation).

    • n_blocks (int, default: 4 ) –

      Number of blocks; 1 gives 0.0.

    • axis (str | None, default: None ) –

      Axis name to split along; default dataset.spatial_axes[0].

    • max_order (int, default: 2 ) –

      As in evaluate_terms.

    • lhs_order (int | None, default: None ) –

      As in evaluate_terms.

    Returns:

    • float –

      The mean coefficient of variation across blocks.

    Raises:

    • ValueError –

      If the dataset is not GRID, the resolved LHS field/axis is absent, or the result is non-finite.

    • InvalidTermsError –

      Propagated from evaluate_terms.

    • EvaluationFailedError –

      Propagated from evaluate_terms when the fit on any block is invalid.

    forward_error 

    forward_error(
    dataset: PDEDataset,
    terms: Sequence[str],
    coefficients: Sequence[float],
    *,
    method: str = "Radau",
    max_step: float | None = None,
    max_seconds: float | None = None,
) -> ForwardError

    Integrate the equation from the data's first time slice and compare.

    Parameters:

    • dataset (PDEDataset) –

      The dataset providing the grid, initial field and target (never mutated).

    • terms (Sequence[str]) –

      RHS term strings of a first-order evolution law.

    • coefficients (Sequence[float]) –

      One coefficient per term.

    • method (str, default: 'Radau' ) –

      scipy.integrate.solve_ivp method.

    • max_step (float | None, default: None ) –

      Maximum solver step; None lets the solver choose.

    • max_seconds (float | None, default: None ) –

      Wall-clock budget in seconds; None sets no limit.

    Returns:

    • ForwardError –

      A ForwardError with value set, or with reason set when the equation diverged, the solver failed, integration was refused (for example a non-GRID dataset, unsupported LHS order or a time-derivative term) or the deadline passed.

    Raises:

    • ValueError –

      If terms and coefficients differ in length, a coefficient is non-finite, max_seconds is not a positive finite number, the error is non-finite, or the resolved LHS field/axis is absent from a GRID dataset.

    • (SearchInterrupted, OutOfMemoryError, RuntimeError) –

      An external stop or an allocation failure inside the integration (kd.core.integrate_pde) propagates.

    ForwardError dataclass

    Outcome of forward_error.

    Attributes:

    • value (float | None) –

      ||pred - u||_2 / ||u||_2 over the full grid, or None when the equation could not be integrated or was not measured.

    • reason (str | None) –

      None when value is set; otherwise "diverged", "solve-failed" (scipy solve_ivp failed), "refused" (the equation or dataset is unsupported) or "timeout" (the max_seconds deadline passed: unmeasured, not a numerical outcome).

    • warning (str) –

      Why integration was refused, failed or stopped, empty on a clean run.

    • terms (tuple[str, ...]) –

      The submitted terms.

    • coefficients (tuple[float, ...]) –

      The submitted coefficients, one per term.

    • input_identity (str | None) –

      compute_dataset_fingerprint of the comparison input with its LHS defaults resolved.

    • interval (tuple[float, float] | None) –

      (t_first, t_last) of the integration, None when the input is not a grid.

    • boundary (Mapping[str, str] | None) –

      Per spatial axis, "periodic" or "held_initial" (both endpoints held at their initial values); None when the input is not a grid.

    forward_error_trajectories 

    forward_error_trajectories(
    trajectories: TrajectorySet,
    laws: Mapping[
        str, tuple[Sequence[str], Sequence[float]]
    ],
    *,
    method: str = "Radau",
    max_step: float | None = None,
    max_seconds: float | None = None,
    rtol: float = 1e-06,
    atol: float = 1e-09,
) -> TrajectoryForwardError

    Integrate one law per state along every trajectory and compare.

    Parameters:

    • trajectories (TrajectorySet) –

      The observed trajectories (never mutated).

    • laws (Mapping[str, tuple[Sequence[str], Sequence[float]]]) –

      Target name to (terms, coefficients), one law per state.

    • method (str, default: 'Radau' ) –

      scipy.integrate.solve_ivp method.

    • max_step (float | None, default: None ) –

      Maximum solver step; None lets the solver choose.

    • max_seconds (float | None, default: None ) –

      Wall-clock budget in seconds; None sets no limit.

    • rtol (float, default: 1e-06 ) –

      Relative tolerance of the solver.

    • atol (float, default: 1e-09 ) –

      Absolute tolerance of the solver.

    Returns:

    • TrajectoryForwardError –

      A TrajectoryForwardError with value, both breakdowns and the predicted trajectories set, or with reason set. Every result names the laws, the input, the intervals and the solver settings.

    Raises:

    • ValueError –

      If a law's terms and coefficients differ in length or a coefficient is non-finite (the message names the law), rtol, atol or max_seconds is not a positive finite number, the observed states are zero everywhere, or the error is non-finite.

    • (SearchInterrupted, OutOfMemoryError, RuntimeError) –

      An external stop or an allocation failure inside the integration propagates.

    TrajectoryForwardError dataclass

    Outcome of forward_error_trajectories.

    Attributes:

    • value (float | None) –

      ||pred - obs||_2 / ||obs||_2 over every trajectory, state and time point, or None when the laws could not be integrated or were not measured.

    • reason (str | None) –

      None when value is set.

    • warning (str) –

      Why integration was refused, failed or stopped, naming the trajectory when a solve failed; empty on a clean run.

    • laws (Mapping[str, tuple[tuple[str, ...], tuple[float, ...]]]) –

      The submitted laws, target to (terms, coefficients), in state order; a key that names no state follows them.

    • input_identity (str) –

      compute_dataset_fingerprint of the trajectories.

    • per_trajectory (Mapping[str, float | None]) –

      Per trajectory id, the relative L2 error over its states and times; None for a trajectory that was not integrated to its end, or whose observed states are all zero (the relative error is undefined; value still includes it).

    • per_target (Mapping[str, float | None]) –

      Per target d<state>_dt, the relative L2 error of that state over all trajectories; None unless value is set, or when that state is zero in every observation.

    • intervals (Mapping[str, tuple[float, float]]) –

      Per trajectory id, (t_first, t_last) of its integration.

    • solver (Mapping[str, float | str | None]) –

      The method, max_step, rtol and atol used.

    • predicted (TrajectorySet | None) –

      The integrated trajectories on the observation times, with the ids and parameters of the input; None unless value is set.

    refit_terms 

    refit_terms(
    dataset: PDEDataset,
    terms: Sequence[str],
    coefficients: Sequence[float] | None = None,
    *,
    small_term_rtol: float = 0.0,
    lhs_order: int | None = None,
    max_order: int = 3,
    method: str = "finite_diff",
    trim: Trim = 0,
    rows: Tensor | None = None,
    surrogate: StoredSurrogate | None = None,
    weak: WeakFormOptions | None = None,
    fixed: Mapping[str, float] | None = None,
    sketch: Sketch | SketchSpec | None = None,
) -> RefitResult

    Prune small terms by their input coefficients, then refit the rest once.

    Parameters:

    • dataset (PDEDataset) –

      The PDE dataset to fit against (never mutated).

    • terms (Sequence[str]) –

      Candidate terms in canonical funcall IR or product notation, as in evaluate_terms; result.terms and result.dropped keep the caller's spelling.

    • coefficients (Sequence[float] | None, default: None ) –

      One input coefficient per term, used only for pruning; required when small_term_rtol > 0.

    • small_term_rtol (float, default: 0.0 ) –

      Relative pruning tolerance in [0, 1).

    • lhs_order (int | None, default: None ) –

      As in evaluate_terms; None takes dataset.lhs_order.

    • max_order (int, default: 3 ) –

      As in evaluate_terms. The default 3 keeps third-order terminal tokens such as u_xxx resolvable.

    • method (str, default: 'finite_diff' ) –

      A registered name from kd.refit_methods(); built-ins are "finite_diff", "autograd", "weak" and "fd2".

    • trim (Trim, default: 0 ) –

      0 (default), a nonnegative integer, a mapping from axis name to a nonnegative integer, or "by_order". Not with autograd as "by_order" (no stencils).

    • rows (Tensor | None, default: None ) –

      Grid-shaped boolean mask or flat integer sample indices.

    • surrogate (StoredSurrogate | None, default: None ) –

      The stored surrogate autograd differentiates (kd.models.load_stored_surrogate); refused by other methods.

    • weak (WeakFormOptions | None, default: None ) –

      WeakFormOptions for method="weak" (None takes the defaults: automatic widths, no correction); refused otherwise.

    • fixed (Mapping[str, float] | None, default: None ) –

      Term to fixed coefficient; see evaluate_terms.

    • sketch (Sketch | SketchSpec | None, default: None ) –

      A kd.Sketch whose pinned terms are the fixed coefficients; see evaluate_terms. A shorthand Sketch binds to the LHS at the resolved lhs_order.

    Returns:

    • RefitResult –

      A RefitResult with mse and frame set, and weak for a weak fit.

    Raises:

    • ValueError –

    from_sympy 

    from_sympy(expr: Expr) -> str

    Serialize a supported SymPy expression into kd function-call IR.

    Supported subset

    Symbol / Integer / Float / Rational / Add / Mul / integer and half-integer Pow / diff_* (single argument) / sin / cos / exp / log / lap. sqrt(x) is Pow(x, 1/2) in SymPy and serializes as sqrt(x); Pow(x, -1/2) as recip(sqrt(x)); any other Pow(x, p/2) as the integer power p of sqrt(x) (for example x**(3/2) as n3(sqrt(x))). A Float exponent whose value is exactly an integer or half-integer (x**0.5, x**2.0) serializes as the power with that Rational exponent.

    Anything outside this subset -- other fractional powers (x**(1/3), x**(3/4)), symbolic exponents (x**x), other Float exponents (x**0.3), Abs, Min / Max, Piecewise, or an unknown Function -- raises ValueError. There is no silent degradation: an unrepresentable expression is a hard failure so callers never receive a lossy approximation.

    Caveat -- operator-name collisions: a Symbol whose name matches a kd IR function (add / mul / div / n2 / n3 / recip / sin / cos / exp / log / sqrt / lap / diff_*) serializes to that bare token, which the kd parser then reads as an operator rather than a variable -- silently changing meaning or failing downstream. Callers must keep symbol names disjoint from kd operator names (kd-internal callers are safe: variable names come from the term library).

    Round-trip preserves supported expressions semantically except when they contain a non-integer Rational that is not exactly representable as a binary float. Non-integer Rationals serialize as one Float literal: exact for values such as 1/2 and 3/4, approximate for values such as 1/3. This keeps the output executable because div(int, int) violates the kd executor's Tensor-only safe-division contract. The serializer also orders Add / Mul by SymPy canonical order, so the exact IR string is not guaranteed (e.g. div(u, x) round-trips to mul(u, recip(x))). SymPy also merges half powers, so n2(sqrt(u)) round-trips to u, which is finite where the original column is NaN (u < 0).

    Parameters:

    • expr (Expr) –

      A SymPy expression in the supported subset.

    Returns:

    • str –

      The kd function-call IR string.

    Raises:

    • ValueError –

      If expr contains a construct outside the supported subset.

      Fewest terms the hole must hold.

    • max_additional_terms (int) –

      Most terms the hole may hold.

    Raises:
