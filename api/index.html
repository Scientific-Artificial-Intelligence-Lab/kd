    API reference

    This reference covers KD's dataset, model, result and analysis entry points, with signatures and parameters from the library. Common entry points are imported from kd, including kd.Model and kd.load_kdv. Batch execution, surrogate transport and plugin interfaces also expose names through kd.harness, kd.models and kd.search; each page gives the import location.

    Descriptions come from the library's own docstrings, cut to reference length. Where a parameter carries more than a sentence of contract, the guide pages in the user guide and design documentation explain it: resume tiers in Parameter tiers and resuming, what the scores mean in Score conventions, term syntax in Equation representation.

    Model and result

    Name Summary
    kd.Model(algorithm, generations[, ...]) High-level facade for PDE discovery (PySR-style API).
    kd.ExperimentResult(best_expression, best_score[, ...]) Serializable value object for a completed experiment.
    kd.SearchInterrupted Stop signal delivered into a running search by its embedding process.

    Name Summary
    kd.instrument_schemas() Return agent-facing schemas of the registered algorithms, in their order.
    kd.instrument_schema_digest() Hash mode and call-configuration declarations, excluding descriptive prose.
    kd.register_algorithm(name, plugin_cls) Register plugin_cls as the algorithm name.
    kd.register_derivative_provider(name, build[, ...]) Register a derivative factory with a stable implementation/configuration ID.
    kd.derivative_providers() Registered provider names in registration order.
    kd.derivative_provider(name) Resolve a registered provider declaration.
    kd.register_sparse_solver(name, solver_cls) Register a constructor, preserving its own keyword contract.
    kd.sparse_solvers() Registered solver names in registration order.
    kd.extension_source(kind, name) Return how the kind extension name was registered.
    kd.extension_origin(kind, name) Return the origin of the kind extension name as a new JSON dict.
    kd.extension_dependencies(kind, name) Return the registration and its declared transitive dependencies once each.
    kd.execution_dependencies(algorithm, mode[, ...]) Origins of exactly the selected algorithm, provider and declared components.
    kd.execution_mode_for_request(algorithm, topology[, ...]) Resolve defaults/selectors and any known input order; absent input context can leave otherwise distinguishable modes ambiguous.
    kd.mode_accepts(mode, topology[, ...]) Route from published declarations, without loading or inspecting data.
    kd.ModeVerdict(accepts, reason[, ...]) Declaration-level applicability and parameters required for this input.
    kd.SGAConfig(num, p_var[, ...]) Configuration for the SGA search algorithm.
    kd.DLGAConfig(mode, library[, ...]) DLGA Stage I (constant-coefficient) configuration.
    kd.DiscoverConfig(n_iterations, seed[, ...]) Configuration for a DISCOVER (RL + optional PINN) search run.
    kd.EqGPTConfig(sparsity_alpha, seed[, ...]) Static configuration for the EqGPT plugin.
    kd.Llm4edConfig(temperature, max_tokens[, ...]) Static configuration for the LLM4ED plugin.
    kd.PySRConfig(terms, seed[, ...]) Frozen configuration for a PySR symbolic-regression run.
    kd.PySINDyConfig(terms, threshold[, ...]) Frozen configuration for a PySINDy STLSQ fit.

    kd.validate_terms(dataset, terms[, ...]) Classify each term as valid / rejected WITHOUT fitting.
    kd.verify_equation(eq, executor[, ...]) Verify an equation on a dataset using its reported coefficients unchanged.
    kd.block_dispersion(dataset, terms[, ...]) Refit the terms on separate grid blocks and measure coefficient spread.
    kd.forward_error(dataset, terms[, ...]) Integrate the equation from the data's first time slice and compare.
    kd.ForwardError(value, reason[, ...]) Outcome of forward_error.
    kd.forward_error_trajectories(trajectories, laws[, ...]) Integrate one law per state along every trajectory and compare.
    kd.TrajectoryForwardError(value, reason[, ...]) Outcome of forward_error_trajectories.
    kd.refit_terms(dataset, terms[, ...]) Prune small terms by their input coefficients, then refit the rest once.
    kd.register_refit_method(name, method) Register a complete measurement method under its declared name.
    kd.refit_methods() Return registered method names, with the built-ins first.
    kd.refit_method(name) Resolve a registered method; unknown names raise ValueError.
    kd.RefitMethod(args, kwargs) A measurement implementation with configuration bound at registration.
    kd.ResolvedFrame(args, kwargs) A fixed target and row/window selection supporting arbitrary subsets.
    kd.FrameFit(coefficients, mse[, ...]) One fixed-support fit, measured on the frame's original target.
    kd.RefitResult(terms, coefficients[, ...]) Outcome of refit_terms.
    kd.RefitFrame(input_identity, lhs_field[, ...]) How one refit measured.

    kd.WeakFormDiagnostics(method_version, spatial_axis[, ...]) What a weak fit integrated and how its solve went.
    kd.ablate_terms(dataset, terms[, ...]) Refit the support, then refit it once without each term.
    kd.AblationResult(baseline, rows[, ...]) Outcome of ablate_terms.
    kd.AblationRow(dropped_term, retained_terms[, ...]) One drop-one refit of ablate_terms.

    kd.TermSetScores(frame, entries) Outcome of score_term_sets: the shared frame and one entry per set.

    kd.PinnRefinement(terms, initial_coefficients[, ...]) Outcome of refine_pinn.

    kd.TermVoteRow(law_key, term[, ...]) The count of one law term across the supports.
    kd.law_signature(eq) Build a versioned signature from an equation's active law.
    kd.format_pde(terms, coefficients[, ...]) Build a formatted PDE equation from term strings and coefficients.
    kd.format_record_equation(record) Format the law a sealed run record carries, for display.
    kd.FormattedEquation(latex, unicode[, ...]) Rendered PDE equation plus the underlying SymPy objects.
    kd.to_sympy(code, strict[, ...]) Convert kd IR into a SymPy expression.
    kd.from_sympy(expr) Serialize a supported SymPy expression into kd function-call IR.
    kd.lower_term(text) Return the funcall IR of one term written in product notation.
    kd.jet_polynomial(expression, vocabulary) Return the expansion of expression as monomial -> float coefficient.
    kd.term_monomial_keys(term, fields[, ...]) Return the monomial keys of one term in the names of one input.

    kd.LhsSpec(field, axis[, ...]) Structured left-hand-side specification for an evolution equation.
    kd.Sketch(pinned, anchored[, ...]) Construct a complete Sketch from typed clauses, or a dataset-bound SketchSpec from shorthand terms and Hole objects.
    kd.SketchSpec(pinned, anchored[, ...]) A shorthand Sketch not yet bound to a dataset; see kd.Sketch.
    kd.Hole(max_terms, min_terms[, ...]) Room for unknown terms in a shorthand Sketch, and the shape they take.
    kd.sketch_from_anchors(dataset, anchors[, ...]) Return a Sketch that requires anchors and admits a bounded rest.
    kd.sketch_from_dict(payload) Strictly decode and revalidate a kd-sketch-v2 payload.
    kd.sketch_to_dict(sketch) Serialize sketch as a JSON-safe kd-sketch-v2 payload.

    kd.EvaluationResult(mse, nmse[, ...]) Result from evaluating an expression or term list.
    kd.TermValidationReport(results, valid[, ...]) Structured result of validate_terms (JSON-dumpable, no fitting).
    kd.TermRejection(term, reason) A single rejected term and the reason it was rejected.
    kd.VerificationReport(signature, form[, ...]) JSON-serializable measurements for one equation on one dataset.
    kd.VerifyPolicy(nmse_max, coeff_atol[, ...]) Thresholds used when reporting and comparing empirical verification.
    kd.SKETCH_EXIT_VERIFY —
    kd.InvalidTermsError(rejected) Raised when one or more terms are rejected and cannot be fitted.
    kd.EvaluationFailedError Raised when the final fit is invalid (solver failure / non-finite MSE).
