    Batch experiments

    kd.harness runs a matrix of fits and keeps what it ran. The loop is four calls: an ExperimentPlan of PlanEntry rows states the matrix, run_plan executes it into a fresh directory, EvidenceStore.load reopens that directory and re-verifies it, and build_consensus groups the runs by the law each one selected. merge_stores combines the stores of separate run_plan batches into one store before that last step. The store's guarantees and the meaning of the consensus axes are described under Batch experiments and evidence.

    These names are imported from the subpackage rather than the package root: from kd.harness import ExperimentPlan, run_plan. Listed below are the entry points a caller writes; the module also carries the artifact machinery that run_plan and build_consensus drive on their own. The last six entries supervise a single worker command and its process group, for a caller that launches its own worker processes: ProcessSupervisor and run_supervised apply a time limit and a SIGTERM, grace, SIGKILL escalation to the whole group, and build_capped_command with check_memory_cap_available adds an optional cgroup memory cap.

    run_plan 

    run_plan(
    plan: ExperimentPlan,
    *,
    datasets: Mapping[str, PDEDataset | TabularDataset],
    store_root: Path,
    model_factory: Callable[..., Any] = Model,
    device: str | None = None,
    recording: RecordingOptions | None = None,
    catalog_path: Path | None = None,
) -> PlanRunResult

    Pre-flight, then run every plan entry serially into a fresh store.

    Parameters:

    • plan (ExperimentPlan) –

      The ordered execution matrix to run.

    • datasets (Mapping[str, PDEDataset | TabularDataset]) –

      Maps each dataset_ref to a loaded PDEDataset or a public TabularDataset (normalized once at entry through the same seam as Model.fit).

    • store_root (Path) –

      Fresh directory for the EvidenceStore (must not exist or must be empty; append/resume is out of scope).

    • model_factory (Callable[..., Any], default: Model ) –

      Facade constructor forwarded to run_episode; injectable so unit tests can stub the fit.

    • device (str | None, default: None ) –

      Execution-environment parameter forwarded to run_episode and, from there, conditionally to the facade. None leaves the serial-execution call form literally unchanged.

    • recording (RecordingOptions | None, default: None ) –

      When set, each entry runs inside a standard run dir <store_root>/runs/entry-NNNN/ (numbered by plan entry, matching records/entry-NNNN.json) wired per the options.

    • catalog_path (Path | None, default: None ) –

      Cross-run ledger to append one kd-runcat-v1 row per outcome (requires recording; rows carry the entry index, the store's plan hash and paths relative to the catalog file).

    Returns:

    • PlanRunResult –

      A PlanRunResult with the store root and one outcome per entry.

    Raises:

    • ValueError –

      If pre-flight finds any unknown instrument or unresolved dataset_ref (all violations are collected into the message), or if catalog_path is given without recording.

    merge_stores 

    merge_stores(
    sources: Sequence[Path | str],
    *,
    root: Path | str,
    name: str,
    version_note: str | None = None,
) -> EvidenceStore

    Merge sealed stores into a new store at root; return it reloaded.

    Parameters:

    • sources (Sequence[Path | str]) –

      Roots of sealed stores, each written by one run_plan batch. Their plan entries are concatenated in this order.

    • root (Path | str) –

      A fresh directory for the merged store (missing or empty).

    • name (str) –

      The merged plan's name; it enters the kd-plan-v1 hash, so a single run_plan over the same entries under the same name has the same plan hash and entry indices.

    • version_note (str | None, default: None ) –

      The merger's conclusion after reading the changelog between the sources' versions: what changed and whether it affects these results. Required when the sources differ in kd_version or git_sha; stored as given otherwise.

    Returns:

    • EvidenceStore –

      The merged store, loaded and fully verified (read-only). report.md is written into root.

    ProcessSupervisor

    Launch a command in its own session and supervise its whole process group.

    Parameters:

    • command (Sequence[str]) –

      Executable and arguments, without shell expansion.

    • env (Mapping[str, str]) –

      Complete environment for the command.

    • hard_seconds (float | None) –

      Elapsed limit from launch, or None for no time limit.

    • grace_seconds (float) –

      Wait after SIGTERM and again after SIGKILL, in seconds.

    • cwd (Path | None, default: None ) –

      Working directory, or None to inherit the current directory.

    • stdout (IO[Any] | None, default: None ) –

      Output handle, or None to inherit stdout. Owned by the caller.

    • stderr (IO[Any] | None, default: None ) –

      Error handle, or None to inherit stderr. Owned by the caller.

    • memory_max_gb (float | None, default: None ) –

      Optional cgroup memory cap in systemd's G units.

    Raises:

    • OSError –

      The command could not be launched.

    abort() -> None

    SIGKILL the group and wait at most one grace period for the leader.

    hurry 

    hurry() -> None

    End the SIGTERM grace now, making SIGKILL due on the next poll.

    poll 

    poll() -> ProcessResult | None

    Advance once, reaping the leader before probing group emptiness.

    Returns:

    • ProcessResult | None –

      None while supervision continues, otherwise its stable result.

    Raises:

    • OSError –

      An OS operation failed. A refused signal still marks its step; an interrupt during the send leaves it pending for retry.

    ProcessResult dataclass

    Observed leader termination, group cleanup, timing and sampled memory.

    Attributes:

    • pid (int) –

      Leader PID, also the supervised process group ID.

    • returncode (int | None) –

      Leader exit status, or None if still alive at the bound.

    • ended_by (ProcessEnding) –

      Last escalation stage reached while the leader was alive.

    • stop_reason (Literal['timeout', 'requested'] | None) –

      timeout or requested when either initiated the escalation; None for natural exit and its descendant cleanup.

    • sigkill_used (bool) –

      Whether the group SIGKILL step was taken, including descendant cleanup and an OS refusal of that signal.

    • started_at (str) –

      Launch time as a UTC ISO 8601 string.

    • term_sent_at (str | None) –

      UTC time of the SIGTERM step, or None.

    • kill_sent_at (str | None) –

      UTC time of the SIGKILL step, or None.

    • ended_at (str) –

      UTC time when supervision finished.

    • wallclock_seconds (float) –

      Elapsed monotonic seconds from launch to completion.

    • peak_rss_bytes (int) –

      Maximum sampled sum of group members' resident memory.

    • left_descendants (bool) –

      Whether the leader exited before escalation and left members requiring cleanup.

    • group_emptied (bool) –

      Whether the group was confirmed empty. False means the post-SIGKILL grace expired with members still present.
