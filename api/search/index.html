    Plugin interfaces

    kd.search holds the machinery behind the algorithm plugins; this page lists the part a plugin author implements, a mode-routing helper, and the record of a run with a reader for its event log. SurrogateTrainer is the protocol an algorithm whose descriptor names config_artifact_keys must satisfy, a train_surrogate method and an artifacts mapping; a registry-level test enforces the pairing for every registered algorithm.

    mode_inputs projects a DatasetReport.to_dict() onto the arguments of kd.mode_accepts, so whether a mode of an algorithm accepts a dataset can be decided from the dataset's report and the published schema alone. RunRecord is the sealed record of one run: its cost, the deterministic evidence, the run specification and the hashes that bind them. last_completed_iteration reads the last completed iteration from a run directory's events.jsonl, including one left by a run that was killed while writing.

    These names are imported from the subpackage rather than the package root: from kd.search import SurrogateTrainer.

    read_run_state 

    read_run_state(run_dir: Path | str) -> RunState

    Return the state a run directory records for its run.

    Three limits of what a directory can say:

    • A process killed outright writes nothing more, so its directory keeps reading preparing or running, exactly like a fit still at work. Whoever started the process knows whether it is alive; the directory does not. An ended process whose directory reads preparing or running was killed.
    • A stop by a budget (max_seconds) or by a callback is not an exception: the fit returns and seals a record, so the state is completed and the record's cost.stop_reason names the stop.
    • The error is recorded only where phase lines are: with phase lines off (RecordingOptions(phases=False)) a raised episode reads failed from its manifest, with no stage and no error. Without phase lines and without a manifest, events.jsonl existing is what says running.

    Raises:

    • FileNotFoundError –

      If run_dir is not a directory.

    • ValueError –

      If manifest.json is not a kd run-directory manifest, or the last phase line is not a kd-runphase-v1 line.

    RunState dataclass

    What a run directory says about its run (read_run_state).

    Attributes:

    • state (Literal['preparing', 'running', 'completed', 'failed', 'interrupted']) –

      "preparing" (no search loop yet), "running" (search loop started), "completed" (the search loop ended, or the directory is sealed completed / no_record), "failed" (the fit raised) or "interrupted" (the fit raised a KeyboardInterrupt or a kd.SearchInterrupted: someone stopped it).

    • sealed (bool) –

      Whether the run-level manifest.json exists. Record, recorder and manifest are written after the search loop ends, so completed with sealed=False is a fit that is still building its result, or one whose caller never sealed the directory.

    • stage (str | None) –

      For failed / interrupted, where the fit was: setup (before fit_started), prepare (before the search loop), search or finalize (after the loop). None when the directory does not say.

    • error_type (str | None) –

      The exception class's qualified name, when recorded.

    • error_message (str | None) –

      The exception's message as the failure line stores it (environment credentials replaced by [redacted:NAME], cut to 2000 characters), when recorded.
