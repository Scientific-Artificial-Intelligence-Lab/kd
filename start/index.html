    Start here

    The steps below install KD, fit the Burgers dataset bundled with the package and open the report of that fit. The home page and the first-fit notebook use the same recipe. Your own data and the language-model controller follow from there.

    Install KD

    On Linux and macOS, create and activate a virtual environment and install the sail-kd distribution:

    python -m venv .venv
source .venv/bin/activate
python -m pip install sail-kd

    Installation gives the Windows activation command, the uv route, the CPU and CUDA builds of PyTorch and the optional components.

    Fit a bundled dataset

    import kd

data = kd.load_burgers()
model = kd.Model(algorithm="sga", generations=5, seed=0).fit(data)
report = model.report("out/first-fit")

    kd.load_burgers() returns the Burgers benchmark as a PDEDataset: the field u on a grid of 256 points in x and 201 in t. kd.Model selects SGA-PDE and runs five generations of its search with a fixed seed, printing the best equation after each generation. With this recipe the fit returns u_t = -u*u_x + 0.1002*u_xx, which print(model.result_.equation) shows; the dataset's reference equation is u_t = -u*u_x + 0.1*u_xx.

    Read the report

    model.report writes every figure the fit supports and one HTML page into out/first-fit/. Open out/first-fit/report.html in a browser, or leave report as the last expression of a notebook cell to display the page inline. The report separates four quantities that answer different questions:

    • The equation is the law the search selected, with its terms and fitted coefficients. The equation card and the coefficient bar chart show the coefficients; the card compares them with the reference equation when the dataset carries one.
    • The native score is the number the algorithm optimizes, here the AIC of SGA-PDE, where lower is better. It ranks candidates within one search and is not comparable across algorithms.
    • The residual compares the time derivative estimated from the data with the right-hand side of the equation evaluated at the same points. The parity plot, the residual figure and the PDE residual field show it; the NMSE in the metadata table at the top of the report summarizes it.
    • The forward prediction integrates the discovered equation in time from the first observed time slice and compares the resulting field with the measured one. The field comparison, the time slices and the error heatmap show it. Errors in the right-hand side accumulate during integration, so this comparison tests the equation as a model of the field rather than of its derivative.

    The remaining figures describe the search itself. The warnings section lists the figures that were skipped or degraded, together with other notes from rendering, such as the boundary condition used for integration. Figure generation describes each figure, and Score conventions describes how candidate terms are refitted against the same data before equations from different runs or algorithms are compared.
